# rewisehome.com

The website for **Rewise**, a smart home company in Malta.

**Rewise Air is on sale now.** It's €27.99, one payment with no subscription, and it comes with free delivery in Malta. Order it at **[rewisehome.com/get](https://rewisehome.com/get)**.

Rewise Air is a small puck that makes any air conditioner with an infrared remote smart. You can control the AC from your phone from anywhere, set schedules and automations, and use Siri or Alexa. The original remote keeps working and stays in sync with the app.
