Using Rewise

  • Use Rewise only with air conditioners, TVs, lights and networks you’re allowed to control.
  • Rewise sends the same infrared signals as your devices’ remotes. It can’t always tell whether a device received a command, so don’t rely on it where a missed command could cause harm (for example to people, pets or equipment that need a set temperature). Keep the original remote.
